# Website recovery resources

assets/: browser-ready chip images, PDFs and group photographs.
data/: snapshot of Hugo structured data for the current website.
originals/: editable chip artwork and merged publication metadata.

The main PowerXLab repository pins this Resources repository as a Git submodule.
Restore with git clone --recurse-submodules https://github.com/power-x-lab-web/PowerXLab.git
Build with Hugo extended 0.159.2. No original D: drive folders are required.
